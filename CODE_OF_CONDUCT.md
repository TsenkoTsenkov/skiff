# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its text applies here in full; it is adopted by reference and not repeated.

In short: be respectful and considerate, assume good faith, keep criticism
about the work and not the person, and do not harass anyone. This applies
to issues, pull requests, discussions and every other space of the
project.

## Reporting

If someone's behaviour in this project is a problem, contact the
repository owner, [@TsenkoTsenkov](https://github.com/TsenkoTsenkov), on
GitHub: mention the owner on the issue or pull request concerned, or use
the contact details on that profile for something you would rather not
post publicly. Abuse can also be reported to GitHub itself with the
"Report content" option in the `…` menu of any comment.

Reports are read by the repository owner, handled confidentially, and
answered. The enforcement guidelines of the Contributor Covenant
(correction, warning, temporary ban, permanent ban) are the scale used.
